Project

Aerofoil Free Flight Data Generator & Analyser

Project details

University of Oxford, October 2022–January 2023. Project led by Professor Luca Di Mare. First-class honours.

Developed a MATLAB free-flight simulator using a finite-element approach. Successive models introduced complexities such as vortex shedding before the final model was validated against existing data and used to optimize aerodynamic parameters from reference flight trajectories.
